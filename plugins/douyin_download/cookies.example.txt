# 抖音登录 Cookie（可选，用于提升受限视频的下载成功率）
#
# 用法：
#   1. 在浏览器登录 https://www.douyin.com/
#   2. 按 F12 打开开发者工具 -> Network(网络) / Application(应用) -> 找到任意抖音请求
#   3. 复制请求头里的 Cookie 整串（形如 sessionid=xxx; ttwid=xxx; msToken=xxx; ...）
#   4. 把这一整串粘贴到本文件（覆盖掉这两行注释），保存即可
#   5. 也可不填本文件，改为在 Web 界面的「抖音登录 Cookie（可选）」框里直接粘贴
#
# 注意：本文件含个人账号信息，已被 .gitignore 忽略，请勿提交到仓库。
#       复制下来的真实 Cookie 请保存为同目录下的 cookies.txt（不是本 example 文件）。
#
# 自动复用说明：当你在 Web 界面「抖音登录 Cookie」框粘贴 Cookie 并成功下载后，
# 本插件会把这串 Cookie 自动写入同目录的 cookies.txt；之后不填框也能复用。
# 一旦保存的 Cookie 失效（登录态过期/被风控），下载会报错并提示你重新粘贴，
# 同时自动清掉失效的 cookies.txt，避免反复用它失败。
#
# 扫码登录（推荐，无需手动复制 Cookie）：
#   在 Web 界面点「扫码登录抖音」生成二维码，用抖音 App 扫码确认后点
#   「完成扫码登录」，凭证会自动写入本目录的 cookies.txt，效果与手动粘贴相同。
#   首次使用会提示安装一次浏览器组件（playwright），按提示执行两条命令即可。
